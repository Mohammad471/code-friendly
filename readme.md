# Code-Friendly

## Learn Smarter. Compare Better. Build Faster.

Code-Friendly is an AI-powered learning platform designed for engineering students.

It provides:

- Structured skill roadmaps
- Topic-wise learning
- Smart Compare Mode
- Practice questions
- Quizzes
- Badges
- XP System
- Progress Tracking

## Tech Stack

Frontend
- React
- TypeScript
- Tailwind CSS

Backend
- Spring Boot
- Java
- Hibernate
- JWT

Database
- MySQL
